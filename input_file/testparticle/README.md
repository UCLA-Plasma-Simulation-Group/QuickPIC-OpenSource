# QuickPIC Input Decks
A sample input deck that using test plasma particles (species profile 200).

The profile 200 has test particles uniformly distributed on a line.

The parameters "x0, x1, y1, y0" define the starting point (x0,y0) and the ending point (x1, y1) of the line.

The parameter "np" is the total partile number on the line. 

The parameters "q, m" define the particle's charge and mass.
